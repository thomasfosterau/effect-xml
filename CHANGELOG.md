- [#111](https://github.com/thomasfosterau/effect-xml/pull/111) [`1e63dc7`](https://github.com/thomasfosterau/effect-xml/commit/1e63dc7274f8f98255c63d3731ceed876ee91d87) Thanks [@thomasfosterau](https://github.com/thomasfosterau)! - Source positions are lazy: the parsers no longer work out a line and column for every token boundary, only for the ones you read.   - Node's `util.inspect` (and so `console.log`) shows the resolved `{ offset, line, column }` / `{ start, end }`.

Measured over the built package in Node 22 on an 8 MB spreadsheet worksheet, the SAX stream is about 2.4 times as fast (~645 → ~265 ms) and `Xml.parse` about 3.9 times (~1420 → ~370 ms); on a document with Japanese element and attribute names, about 2.5 and 3.3 times.
